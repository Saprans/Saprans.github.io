12.1 ТАПСЫРМА / 02

Жеке сайттың мақсаты

Өзім туралы мәлімет пен оқу жұмыстарымды бір жерде көрсету. Оқытушыға презентацияны және эссені сілтеме арқылы ұсыну. Көлсайдағы далалық тәжірибем туралы ой бөлісу.

Электрондық портфолио оқу нәтижелерін жүйелейді.

12.1 ТАПСЫРМА / 03

HTML — беттің құрылымы

HTML — веб-беттің мазмұнын белгілейтін тіл. <h1> негізгі тақырыпты береді. <p> мәтін абзацын жасайды. <a> басқа бетке немесе файлға сілтейді.

<h1>Сәлем, мен Жантаспын.</h1>
<p>ҚазҰПУ-дың 2-курс студентімін.</p>
<a href="essay.html">Эссені оқу</a>

Дереккөз: https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax

12.1 ТАПСЫРМА / 04

CSS — беттің көрінісі

CSS HTML элементтерінің сыртқы көрінісін реттейді. Қаріп, түс, арақашықтық және бағандардың орналасуы CSS арқылы беріледі. Media query шағын экранға бейімдейді.

.hero {
  display: grid;
  grid-template-columns: 1fr 1fr;
}
@media (max-width: 700px) {
  .hero { grid-template-columns: 1fr; }
}

Дереккөз: https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/What_is_CSS

12.1 ТАПСЫРМА / 05

Git және GitHub

Git файлдардағы өзгерістер тарихын сақтайды. Commit белгілі бір өзгерісті тіркейді. GitHub Git репозиторийлерін интернетте сақтауға және ортақ жұмыс жүргізуге мүмкіндік береді. Менің сайт кодым: Saprans/Saprans.github.io

Git — нұсқаларды басқару құралы. GitHub — жобалармен жұмыс істеу платформасы.

Дереккөз: https://docs.github.com/en/get-started/start-your-journey/what-is-github

12.1 ТАПСЫРМА / 06

GitHub Pages — сайтты жариялау

GitHub Pages репозиторийдегі HTML, CSS және JavaScript файлдарынан статикалық сайт жариялайды. Бұл портфолиоға серверлік дерекқор қажет емес. Браузер беттерді және жүктелетін оқу файлдарын ашады.

Репозиторий: Saprans.github.io Басты файл: index.html

Дереккөз: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
