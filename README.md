# Тұрсын Жантас Думанұлының электрондық портфолиосы

Абай атындағы ҚазҰПУ, 2-курс. Ақпараттық-коммуникациялық технологиялар пәнінің 12.1 және 13.2 тапсырмалары.

- `index.html` — жеке сайт және оқу жұмыстарына сілтемелер.
- `styles.css` — сайттың дизайны және мобильді көрінісі.
- `essay.html` — эссенің онлайн нұсқасы.
- `presentation.html` — браузерде ашылатын презентация.
- `files/` — Word эссесі және PowerPoint презентациясы.
- `assets/kolsai.webp` — Көлсай табиғатының көрінісі. Автор: Katariyakartikey, Wikimedia Commons, CC0. Дереккөз: https://commons.wikimedia.org/wiki/File:Kolsai_lake.jpg

Сайт таза HTML және CSS арқылы жасалған. Қосымша JavaScript презентацияны басқаруға және мәзірдегі бөлімді белгілеуге қолданылады. Басты бет пен эссе JavaScript өшірілсе де оқылады.

Жергілікті қарау үшін `index.html` файлын браузерде ашыңыз немесе осы қалтада `python -m http.server 8080` командасын орындаңыз.
